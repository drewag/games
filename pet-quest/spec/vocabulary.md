# Vocabulary

If you searched for a word and landed here, it isn't the word we use. The one we use is in
the first column.

| Term | Means | Defined in | We don't say |
|---|---|---|---|
| Hero | The character the player controls: Ruby or Zachary | world.md | player character, avatar, PC |
| Friend | One of the five pets, met during the game | world.md | pet (in game text), buddy, companion, sidekick |
| Ability | What a friend gives the hero when met | world.md | power, skill, upgrade |
| Friend block | A block in a friend's color, solid only after meeting them | play.md | switch block, palace block, color block |
| Enemy | Anything that costs a heart on touch and can move | world.md | baddie, monster, mob |
| Snack | The collectible, counted as score | play.md | coin, treat, pickup |
| Treat box | A block that drops snacks when bumped from below | play.md | question block, item block |
| Zoomies | The one power-up: speed plus touch-defeats enemies | play.md | star, invincibility |
| Heart | One unit of health | play.md | life, HP |
| Checkpoint | Where the hero restarts after running out of hearts | play.md | save point, flag |
| Level | One course from start to goal | levels.md | stage, course |
| World | A group of four levels, one per friend | levels.md | zone, chapter |
| Bandit | The raccoon boss behind it all | world.md | villain, Bowser |
