# Vocabulary

If you searched for a word in the last column, it isn't one we use. The word in the
first column is the one you want.

| Term | Means | Defined in | We don't say |
|---|---|---|---|
| Racer | The pet you picked and are driving | racers.md | player character, driver, hero |
| Rival | A pet driven by the computer; it uses items too | racers.md | opponent, AI, CPU, enemy, bot |
| Kart | The food-shaped vehicle a pet rides | racers.md | car, vehicle |
| Power | A pet's own special move, one of the items | racers.md | ability, special, super |
| Item | What a snack gives: Banana Peel, Cherry, Bee, Hot Pepper, the rare Star, or the pet's power | play.md | ability, pickup, weapon |
| Spare | The second item held in reserve; tap to swap | play.md | reserve, backup, slot 2 |
| Fork | Where the road splits in two and joins again further on | play.md | split, junction, intersection |
| Branch | The second road at a fork | play.md | alternate route, side path, shortcut path |
| Jump | A narrow boost ramp on the road that launches karts | play.md | ramp jump, launcher, kicker |
| Shortcut | A branch that's quicker than the main road, with hazards | play.md | cut, secret path |
| Boost lane | A branch that's longer than the main road, with boost pads | play.md | bypass, detour |
| Hazard | Rough ground or water across a shortcut, after a ramp | play.md | pit, trap, obstacle, gap |
| Boost pad | The orange arrow patch on a straight that gives a boost | play.md | dash panel, speed pad, booster |
| Snack | Food floating over the track | play.md | pickup, item, coin, collectible |
| Spin out | A kart twirls and slows after a power hits it | play.md | knocked out, stunned, crash |
| Pro driving | The Mario Kart-style controls: Go, Back, Hop, drifting | play.md | hard mode, advanced, manual |
| Drift | Holding Hop through a turn so the kart slides and builds sparks | play.md | powerslide, slide |
| Sparks | The blue, orange and purple glow a drift builds | play.md | charge, mini-turbo level |
| Boost | The burst of speed from letting go of a drift, or a rocket start | play.md | mini-turbo, turbo, speed-up |
| Catch-up | Rivals easing off or speeding up to keep it close | play.md | rubber band, rubberbanding |
| Mini map | The track from above in the top right, with a dot for every kart | play.md | radar, overview, minimap |
| Pick screen | The title screen with the nine cards | play.md | character select, menu |
| Friend | Another person's racer, on another iPad | play.md | remote player, peer, player 2, guest |
| Room | iPads joined to race each other (up to five) | play.md | lobby, session, match, game |
| Room code | The four letters that join a room | play.md | PIN, game code, invite |
| Host | The iPad that made the room; relays messages and drives the rivals | play.md | server, leader, owner |
| Track | One of the courses: Park, Backyard, Kitchen, the harder Snow, Bakery, Toy Room, and the long Beach, Farm, Jungle | look.md | course, level, map, circuit, stage |
